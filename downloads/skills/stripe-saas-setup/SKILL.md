# Stripe SaaS Setup

## When to use
Use this skill when the user explicitly needs this workflow: plan safe subscription billing integration and validation.

## Workflow
1. Confirm the objective, available inputs, constraints, and definition of done.
2. Inspect the relevant evidence before recommending or changing anything.
3. Produce the smallest useful plan and execute only authorized actions.
4. Validate the result against the original objective and likely failure cases.
5. Report the outcome, evidence, caveats, and a safe next step.

## Quality rules
- Never invent facts, test results, usage counts, credentials, integrations, or completed actions.
- Prefer primary evidence and clearly label assumptions.
- Preserve user data and unrelated work.
- Ask before destructive, expensive, public, or irreversible actions.
- Do not claim compatibility with tools or platforms that were not tested.

## Output
Lead with the result. Keep findings prioritized and actionable. Include validation performed and unresolved limitations.
