Privacy

Privacy policy

The current ToolViking calculator library is designed to minimize data collection.

Calculator inputs

Tool calculations run locally in your browser. ToolViking does not receive or store the numbers, text, URLs, or other values you enter into the current tools.

Current site services

The current site does not provide user accounts, payments, advertising trackers, or an application database. Standard hosting infrastructure may process routine request data such as IP address, user agent, requested URL, and timestamps for security and delivery.

External links and email

External services have their own privacy practices. If you email ToolViking, the message and address are handled by the email providers involved so we can respond.

Policy changes

This policy will be updated before materially different data collection, accounts, analytics, payments, or connected services are introduced.

Privacy questions can be sent to hello@toolviking.com.
