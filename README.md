# ToolViking Latest reconstructed master

Dependency-free static site reconstructed on August 14, 2026 from preserved project direction and conversation specifications.

## Run locally

Serve this folder with any static web server. Example: `python -m http.server 8080 -d ToolViking-LATEST`, then open `http://localhost:8080`. Opening individual HTML files directly may break root-relative links.
