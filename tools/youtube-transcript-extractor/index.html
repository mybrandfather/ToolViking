Privacy: the video URL is sent only to the ToolViking transcript endpoint so it can request the available caption track. Transcript text is not stored by this tool.

What this tool can and cannot do

It can retrieve transcripts that YouTube makes available for a video. It cannot create captions for a video that has no accessible transcript track, bypass private-video access, or guarantee that YouTube will accept every server request.
