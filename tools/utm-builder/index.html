UTM Campaign URL Builder

Create a tagged campaign URL with source, medium, and campaign parameters without sending the destination URL anywhere.

The URL is built locally in your browser. Do not place personal, confidential, or sensitive information in UTM parameters.

How to use this tool

How to use the UTM Campaign URL Builder

Enter a complete destination URL, then add consistent source, medium, and campaign values that your analytics reports can group reliably.

  1. Enter the full destination URL, including https://.
  2. Add campaign source, medium, and campaign name.
  3. Build the URL, test it, and copy it into the correct campaign placement.
Method

Formula or calculation method

The builder adds URL-encoded utm_source, utm_medium, and utm_campaign query parameters while preserving valid existing parameters.

Interpretation

What the result means

The result is a shareable tracking URL. Your analytics platform must be installed and configured separately to report visits or conversions.

Example

Worked example

A newsletter link might use source “newsletter”, medium “email”, and campaign “spring-launch” so traffic can be grouped consistently.

Avoid

Common mistakes

Avoid inconsistent capitalization, spaces and naming conventions, duplicate parameters, broken destination URLs, and personal information in tags.

Best use

When to use it

Use it for email, social, partner, QR, display, and other campaign links where you need consistent traffic attribution.

Common questions

UTM Campaign URL Builder FAQ

What are UTM parameters?

UTM parameters are query-string labels commonly used by analytics tools to group campaign traffic by source, medium, and campaign.

Will a UTM link track visitors by itself?

No. The URL carries labels, but an analytics platform must be installed and configured to collect and report the visit.

Can I use spaces in UTM values?

The builder can encode spaces, but a consistent lowercase naming convention with hyphens is usually easier to report and maintain.
